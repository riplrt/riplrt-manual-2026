# /assets

This folder holds the manual's visual and styling assets.

## What lives here

- `styles.css` — custom CSS layered on the Quarto HTML theme (see `_quarto.yml`).
- **Logo** — *placeholder.* Add the RIPLRT Institute logo here (e.g., `riplrt-logo.png` or `.svg`). Once added, you can wire it into `_quarto.yml` under `book:` (for example, a `cover-image:` or a navbar logo) and reference it in `index.qmd`.
- **Figures / images** — diagrams used across chapters (for example, a Community-to-Clinic-to-Cloud schematic, the through-line diagram, or pod-structure figures).

## Conventions

- Use descriptive, lowercase, hyphenated filenames: `community-to-clinic-to-cloud.png`, `pod-structure.svg`.
- Prefer **SVG** for diagrams and **PNG** for raster images.
- Keep source files (e.g., editable diagram files) alongside exports, or note where they live.
- Provide alt text wherever a figure is embedded, for accessibility.
