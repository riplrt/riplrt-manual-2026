# License and Reuse

*RIPLRT Institute Research Group Manual — 2026 Edition (v2.0)*

This repository contains two kinds of material — written content and code — and we recommend licensing them differently so the manual is easy to share while any code remains easy to reuse.

## Manual text, figures, templates, and forms

You are free to share and adapt this material for any purpose, including commercially, provided you give appropriate credit, link to the license, and indicate if changes were made.

**Suggested attribution:**

> *RIPLRT Institute Research Group Manual* (2026 Edition), RIPLRT Institute, licensed under CC BY 4.0.

We chose CC BY in the spirit of the open lab-manual movement that inspired the original RIPLRT manual: other groups should be able to learn from and adapt ours, just as we learned from those who shared theirs.

## Code in this repository

**Recommended: MIT License** (or another permissive OSI-approved license) for any scripts, helper code, or build tooling included in the repository.

The full MIT License text is in the `LICENSE` file at the repository root (copyright line: `Copyright (c) 2026 RIPLRT Institute / Félix E. Rivera-Mariani`). It includes a note clarifying that MIT covers code only and CC BY 4.0 covers the manual text.

If a particular analysis repository has different licensing requirements (for example, due to a sponsor or a dataset's data-use agreement), that repository's license governs its code.

## What this license does **not** cover

The license applies only to original material in this repository. It does **not** grant rights to:

- **Third-party content** — logos, trademarks, dataset contents, or copyrighted figures owned by others. Reuse those under their own terms.
- **Restricted or identifiable data** — governed by IRB approvals and data-use agreements, never by this license. See the Data Governance policy.
- **Completed forms** containing members' names or signatures — these are records, not open content, and should not be redistributed.
- **Institutional branding** — Lynn University and other institutional marks remain subject to their owners' policies.
